## Problem Statement

Creating an engaging mystery investigation game demands low-latency audio cues, clean typographic storytelling, and lightweight backend routing.

## Technical Decisions & Solutions

- **Node.js HTTP Server**: Built a custom lightweight HTTP routing server to serve static assets and handle session endpoints with minimal overhead.
- **Web Audio API Engine**: Engineered custom audio analyzers and sound effects for acoustic clue playback.
- **Tailwind CSS Styling**: Designed a sleek, high-contrast dark theme optimized for long reading sessions and interactive puzzle UI.

## Key Challenges & Results

Flawless audio-visual synchronization during interactive investigation scenes.
