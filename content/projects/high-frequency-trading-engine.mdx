## Problem Statement

High-volume transaction environments require microsecond latency and zero race conditions under concurrent workloads.

## Technical Decisions & Solutions

- **Event-Driven Architecture**: Implemented Kafka for message stream partitioning and gRPC for inter-service communication.
- **In-Memory Orderbook**: Custom lock-free memory layout designed in Go for ultra-fast order matching.

## Key Challenges & Results

Handled up to **50,000 requests per second** with p99 latency staying under **5 milliseconds**.
