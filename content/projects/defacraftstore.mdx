## Problem Statement

Craft artisans and retail customers require an intelligent e-commerce platform capable of providing personalized product recommendations while seamlessly handling automated payment processing and real-time inventory management.

## Technical Decisions & Solutions

- **Laravel 13 & Livewire**: Engineered a highly reactive server-driven frontend architecture eliminating SPA bundle overhead.
- **Gemini AI Chatbot (RAG)**: Integrated Google Gemini AI with Retrieval-Augmented Generation (RAG) to query vector embeddings of craft store products, providing instant conversational support.
- **Midtrans Payment Gateway**: Built automated webhook listeners to handle real-time transaction state updates (pending, settlement, expire).
- **Tailwind CSS & MySQL**: Styled with modern responsive design components and optimized relational schemas for rapid queries.

## Key Challenges & Results

Achieved automated order settlement handling and sub-second RAG response times for product recommendation queries.
