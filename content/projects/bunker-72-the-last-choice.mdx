## Problem Statement

Delivering immersive web-based narrative experiences requires complex state management, spatial audio synthesis, and zero framework overhead.

## Technical Decisions & Solutions

- **Custom Vanilla MVC Architecture**: Designed a decoupled Model-View-Controller framework in pure JavaScript ES6+ without heavy external dependencies.
- **Web Audio API Sound Engine**: Synthesized dynamic ambient soundscapes, sound effects, and audio positional cues directly in-browser.
- **LocalStorage State Engine**: Implemented seamless save/load state serialization for persistent player progression across sessions.

## Key Challenges & Results

Delivered smooth 60 FPS state transitions and responsive audio playback packaged via Vite.
